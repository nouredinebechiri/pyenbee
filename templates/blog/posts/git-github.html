10 commandes Linux indispensables

Les commandes essentielles à connaître pour commencer avec le terminal Linux.

6 août 2026 · 6 min de lecture

Pourquoi utiliser le terminal ?

Le terminal permet d'administrer un système Linux rapidement grâce aux commandes.

1. pwd

Affiche le dossier dans lequel vous vous trouvez. 

pwd

2. ls

Affiche les fichiers et dossiers. 

ls

3. cd

Permet de changer de dossier. 

cd Documents

4. mkdir

Crée un nouveau dossier. 

mkdir projet

5. touch

Crée un fichier vide. 

touch index.html

6. cp

Copie un fichier. 

cp fichier.txt sauvegarde.txt

7. mv

Déplace ou renomme un fichier. 

mv ancien.txt nouveau.txt

8. rm

Supprime un fichier. 

rm fichier.txt

9. cat

Affiche le contenu d'un fichier texte. 

cat fichier.txt

10. sudo

Permet d'exécuter certaines commandes avec des privilèges administrateur. 

sudo apt update
